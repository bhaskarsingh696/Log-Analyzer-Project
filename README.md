# Log-Analyzer-Project
A python backend project  that analyzes server log file to detect error and their frequency.
## Goal
Build a smart log analyzer using core python cocept (no framework) to demonstrate

## Features
-: parse backend log file line by line 
-: Detect error and warnings automatically
-: Display result in terminal (CLI)
-: Clean, object-oriented code structure

## Technologies
-: Pyhton 3.X(Pure python - no framework)
-: file handling 
-: Regular expression
-: OOP (Classes & Inheritance)
